# Directrices del Agente para este Proyecto

Al escribir, modificar o revisar código, el agente debe seguir estrictamente estas reglas:
1. **Código Limpio:** Nombres de variables y funciones descriptivos, funciones cortas y con una sola responsabilidad (principio SOLID).
2. **Mantenibilidad:** Aplicar DRY (Don't Repeat Yourself) y evitar duplicidad de lógica.
3. **Robustez:** Incluir manejo adecuado de errores, validación de entradas y tipado estricto según corresponda.
4. **Revisiones:** Al proponer cambios, explicar brevemente por qué se eligió esa estructura y cómo mejora la calidad del código.
4. **Nombre de archivos:** Nombres de archivos siempre en inglés.
